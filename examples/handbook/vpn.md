# VPN setup

Everyone needs the VPN to reach internal tools such as Grafana and the admin console.

## macOS

Install the WireGuard client from Self Service, then import the profile that IT emails you on your first day. Keep the client running; it reconnects on its own after sleep.

## Windows

Install WireGuard from the Company Portal and import the same profile. If the tunnel shows "handshake did not complete", restart the client and check that your clock is correct.

## Travelling

The VPN works from abroad. Some hotel networks block UDP; if you can't connect, switch to your phone's hotspot.
